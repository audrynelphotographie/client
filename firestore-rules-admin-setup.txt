IMPORTANT FOR ADMIN PORTAL

The Admin Portal is a frontend-only portal. Firebase Firestore will reject SAVE/DELETE if your current Firestore Rules say allow write: if false.

For initial testing only, you can temporarily use:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /clients/{clientId} {
      allow read: if true;
      allow write: if true;
    }
  }
}

After confirming that the panel works, do NOT leave allow write: if true in production. Replace it with Firebase Authentication + admin-only rules.

Client gallery links never contain the access code.
Example:
https://client.audrynel.com/wilson-audry

The client enters the code inside the gallery page. The browser remembers a successful access on that device/browser.
